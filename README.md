## 📌 Overview
This repository presents an exploratory weather analysis of **Dhaka, Bangladesh**, based on approximately **1.5 years of historical weather data**. The project uses notebook-based analysis to uncover trends, seasonality, and variation across key meteorological variables.

---

## 🎯 Project Objectives
- Analyze major weather indicators over time.
- Discover monthly and seasonal weather patterns in Dhaka.
- Visualize trends for clearer interpretation.
- Build a reproducible workflow for weather analysis.

---

## 🧾 Dataset Information
- **Location:** Dhaka, Bangladesh
- **Time Span:** ~1.5 years
- **Data Type:** Time-series weather records
- **Format:** CSV / tabular dataset

## ⚙️ Methodology
1. **Data Collection** – Import historical weather data.
2. **Data Cleaning** – Handle missing values, convert datatypes, and standardize time fields.
3. **Exploratory Data Analysis (EDA)** – Generate descriptive and temporal statistics.
4. **Visualization** – Use plots/charts for trend and pattern analysis.
5. **Interpretation** – Summarize practical weather insights.

## 📊 Key Insights (Replace with your actual results)

- 💧 Humidity increases significantly during monsoon months.

## 🚀 Getting Started
### 1) Clone the repository
```bash
git clone https://github.com/omarsadat123/Weather-Forecast-Dhaka.git
cd Weather-Forecast-Dhaka
```

### 2) (Optional) Create a virtual environment
```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows
```

### 3) Install dependencies
```bash
pip install -r requirements.txt
```

### 4) Run Jupyter Notebook
```bash
jupyter notebook
```
